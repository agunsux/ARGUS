## 1. Executive Overview

**APMI (Asosiasi Promotor Musik Indonesia)** is the official national governing body and professional association representing Indonesia's leading music festival and concert promoters.

Founded to advance the standards, safety, crowd management, and economic scale of Indonesia's live music industry, APMI's members are responsible for **over 85% of commercial concerts and music festivals** held across the archipelago, including Coldplay, Djakarta Warehouse Project (DWP), We The Fest, Pestapora, Joyland, Prambanan Jazz, and major stadium arena tours.

Integrating APMI into TIKUM's Event Intelligence Engine provides an authoritative promoter-to-event directory allowing operators and consumers to query verified events organized by accredited Indonesian promoters at any time.

## 4. Querying APMI Promoters & Events via TIKUM Engine

TIKUM provides programmatic interfaces to query the APMI archive and retrieve linked events:

### 4.1 In-Memory & Service Interface:
```javascript
const { apmiPromoterRegistry } = require('./src/discovery/ApmiPromoterRegistry');
const { canonicalRegistry } = require('./src/discovery/CanonicalEventRegistry');

// 1. Get all APMI accredited promoters
const promoters = apmiPromoterRegistry.getAllMembers();

// 2. Get specific promoter details (e.g. Boss Creator)
const promoter = apmiPromoterRegistry.getMemberBySlug('boss-creator');

// 3. Get all events in Indonesia organized by this promoter
const events = apmiPromoterRegistry.getEventsForPromoter('boss-creator', canonicalRegistry);
```

### 4.2 REST API Interface:
- **`GET /api/discovery/promoters/apmi`**  
  Returns full APMI directory, leadership board, member list, and counts of upcoming/completed events.
- **`GET /api/discovery/promoters/apmi/:slug`**  
  Returns detailed promoter profile (websites, Instagram, signature events) along with all canonical events organized by this promoter.
- **`GET /api/discovery/promoters/apmi/:slug/events`**  
  Returns categorized event list (`upcoming`, `completed`, `archived`) specifically filtered for this promoter.
